Mobility simulation

An autonomous robot drives a loop through the campus. Each network picks a serving cell and performs handovers. Wi-Fi uses sticky-client roaming (8 dB hysteresis, 90–300 ms); 5G uses 3 dB hysteresis (10–25 ms).

      Security: device authentication

      5G uses SIM-style challenge-response: the network sends a random challenge, and only a device holding the registered key can answer correctly. Wi-Fi here uses a shared password. (Simulated; not real 5G-AKA.)
